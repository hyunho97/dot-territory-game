## 이번에 고친 문제와 근거
| 문제 (시뮬레이션에서 발견) | 조치 |
|---|---|
| 방치 플레이가 Lv.4 에서 영구 정체 — 금(Lv.5 레벨업부터 필요)을 건물로 생산할 방법이 없음 | 영주관이 금을 세금으로 생산 (30/시간 × 영지 레벨) |
| 탐험이 건물 생산보다 압도적 (칸당 10초, 1회 3600/시간 급) | 칸당 이동 30초로 증가, 수확량은 영지 레벨당 +25% (후반에도 의미 유지) |
| Lv.10 레벨업 비용(목재 약 7만)이 창고 상한보다 커서 도달 불가능 | 레벨당 기본 상한 +5000, 창고 효과 1500→2500, 레벨업 비용 증가율 1.8→1.9 |
| 한 자원만 몰아 짓는 경우 벌목장 건설 목재 부족으로 정체 가능 (시뮬레이션 정책 문제이기도 함) | 시뮬레이터가 자원 다양성을 고려하도록 수정. 실제 게임에서는 탐험으로 복구 가능 |

## 설계 의도
- 초반(Lv.2)은 2분 — 튜토리얼 체감 속도. Lv.3 부터 실제 기다림이 시작됩니다.
- 접속을 자주 할수록 빠르지만 방치해도 막히지 않습니다 (방치 ≈ 2주, 열심히 ≈ 3~4일).
- 후반(Lv.8→10)이 가장 길고, 그 구간은 건물 업그레이드/창고 확장이 병목입니다.
- 조정 손잡이: `data/territory_levels.json`(`python tools/gen_territory_levels.py --cost-growth N`), `data/buildings.json`(생산량/창고/업그레이드 곡선), `data/exploration.json`, `data/game_config.json`(창고 기본/레벨당).

## 새 콘텐츠가 경제에 주는 영향 (시뮬레이터에는 아직 반영하지 않음)
| 요소 | 규모 | 비고 |
|---|---|---|
| 일일 퀘스트 4개 | 자원 합계 약 1,000 (영지 레벨당 +25%) + 완주 시 장비 1개 | 하루 한 번이라 방치 수입의 보조 |
| 튜토리얼 퀘스트 | 1회성, 합계 자원 약 1,300 | 초반 가속용 |
| 출석 7일 | 7일차 장비 + 금 300 | |
| 탐험 이벤트 | 평균 수확 +4% 수준(추가 수확 +50% × 8% 등) + 보물 금 | 매복은 병력 손실 |
| NPC 침공 | 방어 성공 시 침공군 전투력 × (금 0.3, 철 0.15) | 6시간마다 최대 1회, 패배 시 병력 30% 손실 + 자원 10% 약탈(보호량 제외) |
| 교역소 | 수수료 최대 20% — 자원 총량은 늘지 않고 분배만 바뀜 | 하루 한도로 남용 방지 |
| 연구소 | 생산 +25%, 모집 +25%, 전투 +15%, 탐험 +50% (모두 최대 레벨 기준) | 후반 레벨업 병목 완화 |
→ 연구 '생산 효율'이 시뮬레이션 결과(도달 시간)를 가장 많이 단축합니다. 다음 밸런스 패스에서 시뮬레이터에 연구/퀘스트를 넣어 재측정하세요.

## 연구·퀘스트 반영 시뮬레이션 (tools/balance_sim.mjs `--research/--quests`)

연구소(Lv.5)에서 생산·보급 연구만 투자하고, 일일 퀘스트 + 출석 보상을 매일 수령한다고 가정한 결과 (인간, Lv.10 도달 시간).

| 플레이 | 반영 전 | 반영 후 |
| --- | --- | --- |
| 방치 (탐험 없음, 12h 간격) | 18.2일 | 15.2일 |
| 캐주얼 (2h 간격 탐험) | 7.9일 | 7.3일 |
| 적극 (30분 간격 탐험) | 3.5일 | 3.5일 |

- 방치형은 퀘스트·연구 덕에 약 16% 빨라지고, 적극형은 연구 투자 비용이 초반 업그레이드와 경쟁해 거의 변화 없음 → 격차가 줄어드는 방향이라 현재 값 유지.
- 전술·훈련 연구, 장비, NPC 침공 보상은 시뮬레이터에 아직 미반영.

## 진행 속도 기준 (2026-10 개정)

- 방치형(탐험 없음) Lv.10 도달 ≈ 1년, Lv.3 은 하루 이내. 과금·이벤트 가속 여지를 위해 영지 레벨업 **대기 시간(타이머)** 이 속도를 지배한다.
- 레벨업 대기 시간(`tools/gen_territory_levels.py` TIME_SEC): Lv2 1분 / Lv3 30분 / Lv4 2일 / Lv5 5일 / Lv6 12일 / Lv7 25일 / Lv8 50일 / Lv9 100일 / Lv10 170일.
- 초반 자원 상향(나무 600, 돌 400)과 Lv.3 비용 ×0.35 로 초반 병목 제거.
- 시뮬레이션: 방치 Lv.3 ≈ 32분(12h 접속), Lv.10 ≈ 366일. 적극 플레이도 타이머 때문에 ≈ 365일 → 자원 수급만으로는 단축 불가 (가속 아이템/이벤트로 단축할 설계).

## 점검 후 조정 (2026-10)

- 건물 업그레이드 시간 성장 1.6 → 2.0, 연구 기본 시간 ×3·성장 2.0: 영지 레벨이 1년 타이머로 묶이므로, 건물·연구 대기도 의미 있게 늘려 가속이 쓰임새를 갖도록 함 (Lv.9→10 건물 약 8시간, 연구 5레벨 약 8시간).
- PvE 스테이지 보상: 스테이지당 하루 5회까지만 지급 (`data/pve.json` `dailyRewardWins`). 첫 클리어 가속 보상은 별개.
- 시뮬레이션 재확인: 방치 Lv.3 ≈ 32분, Lv.10 ≈ 367일 (변동 없음).

## 던전·길드 점검 (tools/dungeon_sim.ts, tools/balance_sim.mjs `--guild`)

**던전** (`node --import tsx tools/dungeon_sim.ts`, 실제 전투 엔진 사용, 영지 레벨별 "최대 병력 + 상위 2티어 유닛" 군대, 전투력 배수 1.15 가정)

- 층 클리어 보상이 초기값(금 20/식량 30/철 8)일 때 하루(3회) 순이익은 방치 수입의 2~7% 로 의미가 없었고, 깊은 층은 손실 가치가 보상을 크게 넘음 → 층 보상을 2배(금 40/식량 60/철 16)로 상향.
- 조정 후 최적 목표층 ≈ 15층(Lv.10 은 15~20층), 하루 순이익 ≈ 방치 수입의 12~33% (Lv.3 33%, Lv.5 16%, Lv.7 12%, Lv.10 19%).
- 깊은 층(20층↑)은 손실이 보상보다 커서 일상 파밍이 아니라 "최초 도달 마일스톤(가속/장비) 도전" 용도. 전멸 한계: Lv.3 ≈ 17층, Lv.5 ≈ 22층, Lv.7 ≈ 30층, Lv.10 ≈ 42층.
- 클라이언트에 목표 층 적 전투력과 위험도(안정/손실 큼/전멸 위험)를 표시. 기준: 적 전투력 / 내 전투력 ≤ 0.1 안정, ≤ 0.2 손실 큼, 그 이상 위험.

**길드** (`node tools/balance_sim.mjs --guild on|off`)

- 한 명이 하루 한도(가치 5000)까지 기부하면 경험치 500/일. 기존 레벨 곡선(Lv.10 = 32,000)에서는 혼자서도 65일에 최고 레벨 → 길드원이 모이면 며칠 만에 끝나 목표가 되지 못해 레벨 경험치를 10배로 상향 (Lv.10 = 320,000).
- 조정 후: 혼자 기부 시 Lv.8 도달 ≈ 322일, 15명 길드면 Lv.10 ≈ 43일(혼자의 약 1/15).
- 버프(최대 생산 +9%, 전투력 +4.5%)는 연구(생산 +25%, 전술 +15%)보다 작아 보조 수단으로 적절. 영지 Lv.10 도달 시간에는 영향 없음(타이머 지배).
- 기부 비용은 방치 수입 대비 Lv.3 약 12%, Lv.10 약 4%.

## 길드 보스 레이드 (data/guild_boss.json)

- 방식: 길드장이 소환(소환 후 쿨다운 24시간) → 72시간 동안 길드원이 하루 2번 병력을 보내 공격. 피해 = 출전 병력 전투력 × 0.85~1.15, 공격마다 출전 병력의 5%(종류별 올림)를 잃음. 처치하면 참가자 전원에게 보상 + 길드 경험치, 피해 1위는 장비, 기한 내 못 잡으면 참가자에게 30% 위로 보상.
- 체력 = max(소환 시점 멤버 전투력 합 × 3, 등급 최소 체력). 하한이 있어 소환 직전에 약한 멤버만 모아 쉽게 만드는 방법을 막는다. 등급은 길드 레벨로 결정(트롤 Lv.1~, 화염 거인 Lv.4~, 심연의 용 Lv.7~).
- 조정 근거(예상): 전원이 하루 2번 전 병력을 보내면 약 1.5일에 처치, 참여율 약 50% 면 3일 안팎으로 빠듯한 난이도. 첫 설정(체력 배수 5, 손실 10%)은 참여율 60% 에서도 실패하고 병력 손실이 보상에 육박해 각각 3, 5% 로 낮춤.
- 보상(트롤): 금 1500/철 600/식량 2500 + 가속 30분 ≈ 가치 8천 (영지 Lv.5 방치 수입의 약 12%).
- 실측 확인: 서버 API 로 소환/공격/티켓 제한/처치 보상/쿨다운/기한 만료 보상을 검증.
