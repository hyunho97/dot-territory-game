# 필요한 에셋 목록

`assets/manifest.json` 에 등록하면 코드 수정 없이 플레이스홀더가 교체됩니다.
가져오기 스크립트: 유닛 `tools/import_unit_sprites.py` · 건물 `tools/import_building_sprites.py` · UI/아이콘/이벤트 `tools/import_ui_assets.py`

## 이미 적용된 것 (완료)
- 유닛 27종 전부 (5종족 Tier 1~4 + 5종족 Tier 5)
- 건물 5종족 × 11종(영주관·막사·농장·벌목장·채석장·광산·창고·대장간·주거지·교역소·연구소) × 3단계 = 165장
- 영지 전경 5종족 × 레벨 1~10 = 50장, 종족 선택 라인업 5장
- UI 세트(`image/game_icons_ui_and_events_complete`, 39장): 종족 엠블럼 5, 장비 아이콘 4, 자원 아이콘 5, 연구 아이콘 5, 교역/랭킹/퀘스트/출석/침공 경고/퀘스트 뱃지 아이콘, 출석 카드 2, 탐험 이벤트 일러스트 3, 건설 중 건물, 투사체 2, 지형 타일 3(잔디만 사용), UI 패널/버튼 2(아직 미사용), 제작 완료 이펙트(아직 미사용)
  - 상단 바(자원·엠블럼·버튼 아이콘·퀘스트 뱃지), 종족 선택, 연구 항목, 출석 카드, 접속 리포트 일러스트, 탐사 지도 배경(잔디), 건설 중 목록, 전투 연출(원거리/마법 투사체)에 반영됨

## 1순위: 지금 색 사각형으로 보이는 것
- 없음 — 주거지·교역소·연구소(5종족 × 3단계 = 45장)와 엘프/드워프/오크 Tier 5 유닛 3종까지 모두 적용됨

## 2순위: 새 콘텐츠(던전·길드·보스·가속) — 지금은 글자 화면
- [ ] 길드 보스 초상 3종 (트롤/화염 거인/심연의 용): 128×128 이상 — `boss/troll`, `boss/giant`, `boss/dragon` (보스 체력바 위에 표시)
- [ ] 던전 입구/층 일러스트 1~2장 (던전 창 상단 배너, 가로형 권장)
- [ ] 길드 문장(엠블럼) 1장 + 길드 배너 (길드 창 상단)
- [ ] 가속 아이콘 (모래시계 등, 32×32) — 보유 가속 표시와 버튼에 사용 예정
- [ ] 상단 바 버튼 아이콘 나머지 7개 (영지/막사/대장간/전투/탐사/던전/길드, 32×32) — 지금은 글자만
- [ ] 보상 결과 일러스트(선택): 던전 클리어, 보스 처치/실패, 길드 레벨업
- [ ] 장비 등급 테두리 5종(일반~전설) 또는 등급별 색 프레임 (장비 아이콘 4종은 적용됨)

## 3순위: 있으면 좋은 것
- [ ] 걷기/공격/피격 애니메이션 프레임
- [ ] 후속 건물: 마법탑/사원/성벽/훈련장/용의 둥지/묘지
- [ ] 지형 타일 `path`, `water` 는 받았지만 아직 쓰는 곳이 없음(탐사 지도를 길/물이 있는 지도로 바꿀 때 사용)
- [ ] UI 패널/버튼은 받았지만 9-slice 로 늘리면 모양이 깨질 수 있어 적용 보류 — 9-slice 용 가장자리 크기(px) 또는 크기별 버전이 있으면 알려 주세요
- [ ] 제작 완료 이펙트(`fx/craft_complete`)는 대장간에 "제작 완료 연출"을 넣을 때 사용 예정
- [ ] 도트 폰트 로컬 파일 (현재 Google Fonts DotGothic16 사용 — 오프라인 필요 시)
- [ ] 효과음/배경음악 (현재 없음)

## 이미지 외에 정해야 할 것
- 영지 화면에서 건물 배치 방식 (현재는 오른쪽에 종류별로 나열)
- 비밀번호 변경/찾기, 이메일 인증 여부
- 과금/가속 상점 연결 방식
